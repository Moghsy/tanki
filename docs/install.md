# Installing tanki

tanki is a single binary. Linux release archives are built against glibc
(Ubuntu 22.04 baseline, glibc 2.35 or newer). They are not static musl
builds, because a static binary cannot load the ALSA plugins that route
audio to PipeWire or PulseAudio.

## From a release archive (Linux x86_64 or aarch64)

```sh
sha256sum -c tanki-VERSION-x86_64-unknown-linux-gnu.tar.gz.sha256
tar -xzf tanki-VERSION-x86_64-unknown-linux-gnu.tar.gz
cd tanki-VERSION-x86_64-unknown-linux-gnu
install -Dm755 tanki ~/.local/bin/tanki
install -Dm644 man/man1/*.1 -t ~/.local/share/man/man1/
```

Runtime requirements: glibc and `libasound.so.2` (package `libasound2` /
`libasound2t64` on Debian and Ubuntu, `alsa-lib` elsewhere). Optional
programs that tanki uses when present: `mpv` (video), `speech-dispatcher`,
`espeak-ng` or Piper (text to speech), `latex` with `dvipng`/`dvisvgm`
(legacy LaTeX images, only with `--generate-latex`).

## Shell completions

The archive ships bash, zsh and fish scripts in `completions/`; any shell
clap supports can also be generated by the binary itself:

```sh
# bash
tanki completions bash > ~/.local/share/bash-completion/completions/tanki
# zsh (a folder on $fpath)
tanki completions zsh > ~/.zfunc/_tanki
# fish
tanki completions fish > ~/.config/fish/completions/tanki.fish
```

`tanki completions elvish` and `tanki completions powershell` work the same
way.

## Man pages

`tanki.1` plus one page per subcommand (`tanki-sync-login.1`, …). From a
source build: `tanki man-pages DIR` writes them into `DIR`.

## From source

Prerequisites: Rust 1.97.1, a C compiler, protoc 31.1 (any release with
proto3 `optional` support), pkg-config and the ALSA development headers
(`libasound2-dev` on Debian and Ubuntu).

```sh
git clone <repository> tanki && cd tanki
export PROTOC=/path/to/protoc
cargo xtask setup          # pinned Anki checkout and its patches
python3 scripts/cargo-bounded.py build --release --locked -p tanki-cli
install -Dm755 target/release/tanki ~/.local/bin/tanki
```

The optional `blitz` feature (`-p tanki-cli --features blitz`) adds the T2
rendering tier for heavily styled cards. On Linux, building this feature also
requires the Fontconfig development headers (`libfontconfig1-dev` on
Debian/Ubuntu).

Distribution packages (Homebrew, AUR, Nix) will be added when tanki is
published.

## First run

Close Anki desktop, then run `tanki`. It finds your profile where desktop
does and backs the collection up the first time it opens it. See the README
for profile selection, sync with a self-hosted server and `tanki serve`.
